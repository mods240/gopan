# 🥐 ゴパン

> 助手席で見つけて、運転手に届ける  
> 京阪神のパン屋を、ドライブ中に見つけよう

## 概要

「ゴパン」は、ドライブ中・徒歩・電車移動中に、近くのパン屋を見つけるためのPWAアプリです。
助手席の人がパン屋を探し、運転手にスワイプで送る「2人で使うパン屋ナビ」を目指しています。

## 名前の由来

「**ご**飯」+「**パン**」=「ゴパン」  
「朝ごはん買って帰ろう」と言いつつパンを買う、その日常から生まれた言葉。

## 技術スタック

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Supabase (PostgreSQL + Realtime)
- OpenStreetMap (Overpass API)
- Leaflet
